# Lessons

## 2026-04-11

- Re-audit README claims after any README edit instead of assuming previously identified mismatches still stand or are fully resolved.
- When documentation claims quantitative results, deployment details, or security properties, verify them directly against the current source files before calling the README accurate.

## 2026-07-28

- When a deployed provider is already working and only a preview model has disappeared, preserve the provider and switch to a supported GA model unless the user explicitly asks for a provider migration.
